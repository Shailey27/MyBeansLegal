# Bean Book Legal Pages

This repository contains the public legal documentation for **Bean Book** (previously published as MyBeans), a private coffee journal for iOS. The pages match the app's design system — cream/copper "lab" aesthetic with light and dark mode.

## About Bean Book

Bean Book helps coffee enthusiasts:

- Track and organize their coffee bean collection, tastings, and recipes
- Scan coffee bag labels with the camera to fill in bean details automatically
- Dial in espresso with the on-device AI Dial-In Assistant and Puck Diagnosis (Bean Book Pro)
- Analyze flavors with an SCA-style flavor wheel and personal palate profile
- Discover and import beans from roaster websites
- Keep everything local — no accounts, no analytics, no tracking
